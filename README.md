# ヨルログ — 寝る前5分の、こころの筋トレログ

アプリ開発コンペ提出物。「忙しい社会人のための"寝る前5分"ジャーナリングアプリ」。

単一HTMLファイル `index.html` をブラウザで開くだけで動作します。

---

## ジャーナリングの3つの課題に、どう答えたか

| 課題 | このアプリの答え |
|---|---|
| **書きたいのに、続かない** | 入力の主役をタップにした3ステップ（からだ・こころ／効いた・削られた／ひとこと）。問いはコンディションに応じて出し分け、**前夜のAIが置いていった問い**が翌晩いちばん上に出る。書けない夜は「ことばが出ない夜」モードで単語3つでも記録が閉じる。 |
| **吐き出したのに、整理されない** | まとめは「見出し／できごと／きもち／本人の言葉の引用／気づき／できていたこと／明日の5分」に構造化。SYSTEMプロンプトで一般論・励まし・説教・診断を禁止し、**本人が書いた語句の引用を毎回強制**している。 |
| **続けたのに、変化が見えない** | タグごとの効き目（ついた日のこころ平均 − つかない日の平均）を**アプリ側で先に計算してAIに渡し**、〈数値＋本人の言葉〉を根拠にした「回復スイッチ」「気づいていない回復スイッチ」「考え方のクセ」「動いたもの（before→after）」を出力。見出しが日付順に積み上がる背表紙リストと推移グラフで、AIを待たずに変化が見える。 |

---

## 使い方

1. `index.html` をブラウザで開く（ダブルクリックで可。サーバー不要）
2. 初回に設定ダイアログが開くので、**LLMプロバイダとAPIキー**を入力して保存
   - Anthropic（既定・`claude-opus-5`）／ OpenAI ／ Google Gemini から選択
   - キーはブラウザの localStorage にのみ保存され、ソースコードには含まれません
3. ホームの **「サンプル日記」** を押すと、審査用サンプル（田中さんの6/2〜6/8）を
   取り込み → そのままふりかえり生成まで走ります
4. **「今夜を記録する」** から、1日ぶんの通常フローを試せます

> `file://` から Anthropic API を直接呼ぶため、
> `anthropic-dangerous-direct-browser-access: true` ヘッダを付与しています。

---

## 画面

- **ホーム** — 昨夜の自分からの問い／記録した日・連続した日・こころ平均／見出しの背表紙／推移グラフ
- **記録（3ステップ）** — コンディション → 今日の内訳 → 今夜のひとこと
- **その日のまとめ** — 見出し・引用・整理・気づき・できていたこと・明日の5分・明日への問い
- **ふりかえり** — 週の見出し／気づいていない回復スイッチ／回復スイッチ／削られていたもの／
  考え方のクセ／動いたもの／来週の実験／見出し一覧

## 安全設計

- 用途を日常の内省・記録に限定。AIのまとめは決めつけ・心理診断ではなく、本人の言葉を映して整理するもの
- SYSTEMプロンプトで、病名・症状の判断・受診や治療の指示・性格や原因の断定を禁止
- 深刻な語を **送信前にブラウザ内で検知**し、公的な相談窓口を提示（よりそいホットライン／
  こころの健康相談統一ダイヤル／厚生労働省「まもろうよ こころ」）
- 全画面のフッターに、常時相談窓口への導線

## APIキーの扱い

ソースコード内の `API_KEY_PLACEHOLDER` は空文字のままです。
キーは実行時にUIから入力し、そのブラウザの localStorage にのみ保存されます。
送信先は選択したプロバイダのエンドポイントのみです。
