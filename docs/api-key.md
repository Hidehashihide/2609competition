# APIキーの取得と設定

このアプリは実行時にLLM APIを呼びます。キーはソースコードに含まれていないため、
**ご自身でキーを発行し、アプリの ⚙︎ 設定から入力**してください。
入力したキーはそのブラウザの localStorage にのみ保存されます。

対応プロバイダは3つ。**Anthropic と Google Gemini は、ローカルの `index.html`（`file://`）から
直接呼べることを実測で確認済み**です。

---

## A. Google Gemini ── 無料で始めたい場合

クレジットカード登録なしで始められます。

1. [Google AI Studio の APIキー画面](https://aistudio.google.com/apikey) にGoogleアカウントでログイン
2. 「Create API key」を押してキーを作成し、コピー（`AIza…` で始まる文字列）
3. アプリの ⚙︎ →「LLM プロバイダ」で **Google Gemini** を選ぶ
   （モデル欄は自動で `gemini-3.6-flash` になります）
4. APIキー欄に貼り付けて「保存する」

無料枠は `gemini-3.6-flash` で 1日1,500リクエスト程度。このアプリは
1日の記録＝1回、ふりかえり＝1回しか呼ばないため、枠内で十分収まります。

> **モデル欄は触らずに、まず「保存して接続をテストする」を押してください。**
> 使えるモデルはキーの発行時期やアカウントによって変わります
> （例：`gemini-2.5-flash` は新規キーでは提供終了しています）。
> テストに失敗した場合、アプリが **そのキーで実際に使えるモデルの一覧** を取得して
> ボタンで表示します。押すだけで設定され、自動で再テストされます。

## B. Anthropic（Claude）── 出力品質を優先する場合

審査は出力品質で行われるため、既定は最上位の `claude-opus-5` にしています。
前払いのクレジット購入（最低 $5 程度）が必要です。

1. [Anthropic Console](https://console.anthropic.com/) に登録・ログイン
2. **Billing** でクレジットを購入（最低 $5 程度から）
3. **Settings → API keys** で「Create Key」、`sk-ant-…` をコピー
   （キー全体が表示されるのは作成時の一度だけです）
4. アプリの ⚙︎ → プロバイダ **Anthropic**、APIキー欄に貼り付けて「保存する」

### 費用の実測見積り

このアプリが実際に送信するプロンプトの文字数から算出したものです。

  取り込み（サンプル7日分）  入力 約 3,100 文字
  ふりかえり生成             入力 約 6,100 文字
  1日分のまとめ              入力 約 3,500 文字
  ────────────────────────────────
  合計                       入力 約 12,800 文字 ／ 出力 約 5,300 文字

Claude Opus 5 は入力 $5・出力 $25（100万トークンあたり）。
**サンプルを一通り流して30〜60円程度**です（思考トークンを多めに見た場合で60円）。
最低購入額の $5 で100回以上の試行ができます。動画の撮り直しを何度しても足りる水準です。

## C. OpenAI

1. [OpenAI Platform](https://platform.openai.com/api-keys) でキーを作成（`sk-…`）
2. アプリの ⚙︎ → プロバイダ **OpenAI**、モデルは既定 `gpt-4o`

> 注：OpenAI については、開発環境のネットワーク制限のため
> `file://` からのブラウザ直接呼び出しを実測できていません。
> 動画収録の前に、必ず一度動作をご確認ください。

## うまくいかないとき

アプリはエラー内容をそのまま画面に出します。

| 表示 | 原因と対処 |
|---|---|
| `API エラー 401` / `403` | キーが違う、失効している、権限がない。⚙︎ から入力し直す |
| `API エラー 404` | モデル名が違う。⚙︎ のモデル欄を既定値に戻す |
| `API エラー 429` | そのモデルの利用枠切れ。**無料枠の対象は Flash / Flash-Lite 系に限られることがあります。** エラー画面に出るモデルのボタン（左ほど無料枠が残りやすい順）を押すと、切り替えて自動で再試行します |
| `Failed to fetch` | ネットワーク遮断、または社内プロキシ・拡張機能によるブロック。別の回線で試す |
| 出力が上限に達しました | 記録日数を減らすか、モデルを変える |

## 実装上の注意（Gemini）

Gemini の `responseSchema` は OpenAPI 形式のため、一般的な JSON Schema とは 2 点異なります。
本アプリではリクエスト送信時に自動変換しています（`toGeminiSchema()`）。

- `additionalProperties` を受け付けない → 送信前に除去
- 型名は大文字（`STRING` / `OBJECT` / `ARRAY` / `INTEGER`）でなければならない → 送信前に変換
- Gemini 2.5 系は思考トークンも `maxOutputTokens` を消費する → 上限を 3 倍に確保

## 安全のために

- 発行したキーは他人と共有しない。**提出するソースコードにも書かない**
  （`index.html` の `API_KEY_PLACEHOLDER` は空文字のままにしてください）
- 動画を収録する際は、⚙︎ の設定画面をカメラに映さない
- 提出後にキーが不要になったら、各コンソールから失効させておくと安心です
