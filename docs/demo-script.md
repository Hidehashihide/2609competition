# 提出物② 動作動画 進行案（2〜3分）

収録前に：⚙︎ →「記録を全消去」でまっさらな状態にし、APIキーを設定しておく。

| 時間 | 画面 | 操作・ナレーション |
|---|---|---|
| 0:00–0:15 | ホーム | 起動。「寝る前5分、3タップとひとことだけのジャーナリングアプリです」 |
| 0:15–0:55 | 記録 3ステップ | 「今夜を記録する」→ からだ／こころをタップ → 効いた・削られたをタップ → **問いがコンディションに応じて変わる**ことに触れる →「別の問いにする」「ことばが出ない夜」も一瞬見せる → ひとこと入力 |
| 0:55–1:20 | その日のまとめ | 生成 → 見出し・本人の言葉の引用・気づき・できていたことを読み上げる → **最後の「明日のあなたへ、置いていく問い」** を強調（＝翌晩の入力ガイドになる） |
| 1:20–1:30 | ホーム | 戻ると、その問いが一番上に出ていることを見せる（白紙にしない仕組み） |
| 1:30–1:45 | 取り込み | 「サンプル日記」を押す → 7日分が日付ごとに切り分けられ、コンディションとタグが推定される |
| 1:45–2:40 | ふりかえり | **① 気づいていない回復スイッチ**（本人が自分の手柄に数えていないもの）を最初に読む → **② 回復スイッチ**が〈数値＋本人の言葉〉を根拠にしていることを指摘 → 考え方のクセ（日付つきの根拠と引用） → **before→after の変化** → 来週の実験 |
| 2:40–2:55 | ホーム | 見出しの背表紙と推移グラフをスクロール。「続けた分だけ、読み返せる本になります」 |

**必ず映しておきたい3点**
1. 問いが日によって変わる／前夜のAIの問いが翌晩トップに出る
2. ふりかえりの evidence に **数値と本人の言葉の引用が両方入っている**
3. blindspot（気づいていない回復スイッチ）が、単なる要約では出ない内容であること
