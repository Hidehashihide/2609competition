### 出力で確認すべき観点

| 見るところ | 合格の条件 |
|---|---|
| ふりかえり「自分を測っている基準」 | 田中さんの言葉（6/3「ただ回してるだけなのか」等）が日付つきで引用されている |
| ふりかえり「このズレについて」 | 一般論でなく、ジム／人との関わりの具体に触れている。詰問調でない |
| 「消えかけている気づき」 | 6/5か6/6の本人の言葉が引用され、その後どうなったかが日付で示されている |
| 回復スイッチの evidence | **数値と本人の言葉の引用が両方**入っている |
| その日のまとめの締めくくり | 「お疲れさま」等の一般論でなく、その日の具体に触れて静かに終わっている |

**期待外れだった項目があれば、その欄のプロンプト指示を追い込みます。遠慮なくお知らせください。**
